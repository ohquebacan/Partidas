# Partidas

Partidas guardadas completas de juegos de Nintendo Switch, para restaurarlas desde la consola con [JKSV BACAN](https://github.com/ohquebacan/JKSV-BACAN).

Cada archivo está tal como lo publicó su autor en GBAtemp; aquí solo se aloja para que la consola pueda bajarlo. El catálogo que usa JKSV está en [OQB-HATS-PACK](https://github.com/ohquebacan/OQB-HATS-PACK) (`partidas.json`).
